## 项目简介

Sausage Recorder SDK 是一个跨平台的屏幕录制解决方案，提供完整的 Unity 集成插件以及 Android、iOS 原生开发工程。

### 主要功能

- **跨平台支持**：支持 Android 和 iOS 平台的屏幕录制
- **统一 API**：提供统一的 Unity C# API，简化跨平台开发
- **高质量录制**：支持多种清晰度档位和自定义配置
- **完整集成**：包含 Unity Package、Android 原生工程和 iOS 原生工程

### 项目结构

- **Package/** - Unity Package 插件，包含 C# 脚本、平台插件和示例代码
- **android/** - Android 原生开发工程，包含完整的 SDK 源代码和构建配置
- **ios/** - iOS 原生开发工程，包含完整的 SDK 源代码和构建配置

### 快速开始

1. **Unity 集成**：查看 [Package/README.md](Package/README.md) 了解如何集成 Unity Package
2. **Android 开发**：查看 [android/README.md](android/README.md) 了解 Android SDK 详情
3. **iOS 开发**：查看 [ios/README.md](ios/README.md) 了解 iOS SDK 详情

## 测试用例

### 用例1：完整录制流程
1. 启动应用
2. 点击"开始录制"
3. 授权屏幕录制权限
4. 观察录制状态和进度
5. 点击"停止录制"
6. 验证文件生成

### 用例2：暂停恢复测试
1. 开始录制
2. 点击"暂停"
3. 验证状态变为PAUSED
4. 点击"恢复"
5. 验证状态变为RECORDING
6. 停止录制

### 用例3：质量调整测试
1. 开始录制
2. 点击"高质量"按钮
3. 验证质量调整回调
4. 点击"低质量"按钮
5. 验证质量调整回调
6. 停止录制

### 用例4：格式转换测试
1. 录制一个短视频
2. 点击"转GIF"按钮
3. 验证转换结果
4. 点击"转WEBM"按钮
5. 验证转换结果

### 用例5：错误恢复测试
1. 在录制过程中点击"错误恢复"
2. 验证状态重置为IDLE
3. 验证资源清理
4. 重新开始录制

## 性能基准

### 内存使用
- 空闲状态：< 50MB
- 录制中：< 200MB
- 长时间录制：内存稳定

### 录制质量
- 高质量：1080p, 5Mbps
- 中质量：720p, 3Mbps
- 低质量：480p, 2Mbps

### 文件大小
- 1分钟高质量：约30-40MB
- 1分钟中质量：约20-25MB
- 1分钟低质量：约10-15MB

## 已知限制

1. **格式转换**：当前实现为简化版本，实际项目中需要集成FFmpeg
2. **GIF生成**：需要MediaMetadataRetriever提取帧
3. **低版本兼容**：Android 7.0以下暂停/恢复使用软策略
4. **性能影响**：录制可能影响游戏FPS，建议在非关键场景使用

## 调试技巧

1. **日志查看**：使用`adb logcat | grep RecordingManager`
2. **状态检查**：使用"详细状态"按钮查看完整状态
3. **内存监控**：观察内存使用百分比变化
4. **文件检查**：在`/Android/data/com.funny.replay/files/replay/`目录查看生成文件

## 问题排查

### 录制失败
1. 检查权限是否授予
2. 检查设备是否支持屏幕录制
3. 查看错误日志
4. 尝试错误恢复

### 文件生成失败
1. 检查存储空间
2. 检查文件路径权限
3. 验证录制状态
4. 查看详细状态信息

### 性能问题
1. 降低录制质量
2. 检查内存使用
3. 关闭其他应用
4. 使用错误恢复重置状态

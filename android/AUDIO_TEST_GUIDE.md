# 音频测试功能使用指南

## 功能说明

在simple应用中新增了音频测试功能，用于测试录屏时音频是否正常录入。

## 使用方法

1. **播放测试音频**：
   - 点击"播放测试音频"按钮
   - 应用会播放一个2秒的测试音调
   - 音调会自动停止

2. **停止音频**：
   - 点击"停止音频"按钮可以手动停止正在播放的音频
   - 音频播放完成后会自动停止

## 测试录屏音频的步骤

1. 启动simple应用
2. 点击"播放测试音频"按钮，确认能听到测试音调
3. 点击"开始录制"按钮开始录屏
4. 在录制过程中，再次点击"播放测试音频"按钮
5. 录制几秒钟后，点击"停止录制"
6. 播放录制的视频文件，检查是否包含音频

## 技术实现

- 使用`ToneGenerator`生成测试音频，更简单可靠
- 音频通过`AudioManager.STREAM_MUSIC`流播放
- 音量设置为80%，确保音频清晰可听
- 自动管理音频资源，避免内存泄漏

## 注意事项

- 测试音频播放时间为2秒，会自动停止
- 如果音频已在播放中，再次点击播放按钮会提示"音频已在播放中"
- 应用退出时会自动清理所有音频资源
- 确保设备音量已开启，以便听到测试音频

## 故障排除

如果听不到测试音频：
1. 检查设备音量是否开启
2. 检查是否开启了静音模式
3. 查看日志输出，确认音频播放是否成功
4. 尝试重启应用

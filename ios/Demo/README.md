# SausageReplay iOS Demo

这是一个完整的iOS Demo应用，用于演示和测试SausageReplay iOS SDK的所有功能。

## 功能特性

### 🎯 核心功能演示
- **SDK初始化**：支持MidRange和HighEnd两个设备档位
- **录制控制**：开始、停止、暂停、恢复录制
- **质量调整**：支持Low、Medium、High三个质量等级
- **权限管理**：麦克风权限的检查和申请
- **实时监控**：内存使用情况实时显示

### 📱 用户界面
- **状态显示**：实时显示SDK状态、版本、档位信息
- **控制按钮**：直观的录制控制界面
- **配置选项**：质量、档位、音频、时长等参数设置
- **日志系统**：详细的操作日志和错误信息

### 🔧 技术特性
- **实时反馈**：录制进度、文件大小实时更新
- **错误处理**：完整的错误码和错误信息显示
- **性能监控**：内存使用情况监控
- **日志记录**：所有操作都有详细日志记录

## 构建和运行

### 1. 环境要求
- Xcode 15.0+
- iOS 12.0+
- macOS 12.0+

### 2. 构建步骤

#### 方法一：使用构建脚本（推荐）
```bash
cd ios/Demo
./Scripts/build_demo.sh
```

#### 方法二：使用Xcode
1. 打开 `SausageReplayDemo.xcodeproj`
2. 选择目标设备或模拟器
3. 点击运行按钮 (⌘+R)

### 3. 构建选项

构建脚本支持多种选项：

```bash
# 完整构建
./Scripts/build_demo.sh

# 只构建SDK
./Scripts/build_demo.sh -s

# 只构建Demo应用
./Scripts/build_demo.sh -d

# 构建并生成IPA文件
./Scripts/build_demo.sh -i

# 构建模拟器版本
./Scripts/build_demo.sh --simulator

# 运行测试
./Scripts/build_demo.sh -t

# 清理构建目录
./Scripts/build_demo.sh -c
```

## 使用指南

### 1. 初始化SDK
1. 选择设备档位（MidRange或HighEnd）
2. 点击"初始化SDK"按钮
3. 查看日志确认初始化成功

### 2. 权限管理
1. 检查麦克风权限状态
2. 如需要，点击"请求权限"按钮
3. 在系统弹窗中授权

### 3. 录制配置
- **质量选择**：Low (480p)、Medium (720p)、High (1080p)
- **档位选择**：MidRange（中端）、HighEnd（高端）
- **音频开关**：是否包含麦克风音频
- **录制时长**：5-120秒可调

### 4. 开始录制
1. 配置好参数后，点击"开始录制"
2. 首次录制会弹出系统屏幕录制权限对话框
3. 授权后开始录制，可实时查看进度

### 5. 录制控制
- **暂停/恢复**：录制过程中可暂停和恢复
- **质量调整**：录制过程中可调整质量
- **停止录制**：点击停止按钮结束录制

### 6. 查看结果
录制完成后，日志会显示：
- 文件路径
- 文件大小
- 录制时长
- 错误信息（如有）

## 故障排除

### 常见问题

1. **初始化失败**
   - 检查iOS版本是否支持（需要iOS 12.0+）
   - 确认设备支持屏幕录制

2. **权限问题**
   - 检查Info.plist中的权限描述
   - 确认用户已授权麦克风权限

3. **录制失败**
   - 检查存储空间是否足够
   - 确认没有其他应用在使用屏幕录制

4. **文件问题**
   - 检查应用沙盒权限
   - 确认输出路径有效

### 调试技巧

1. **查看日志**
   - 应用内日志显示所有操作
   - Xcode控制台显示系统日志

2. **内存监控**
   - 实时显示内存使用情况
   - 监控内存泄漏

3. **性能分析**
   - 使用Xcode Instruments分析
   - 监控CPU和内存使用

## 开发说明

### 代码结构
- `ViewController.m`：主控制器，包含所有UI逻辑
- `SRRecordingCallback`：实现录制回调协议
- Storyboard：使用Interface Builder设计界面

### 关键实现
- 使用`SRRecordingManager`进行录制控制
- 使用`SRPermissionManager`管理权限
- 使用`SausageReplayIOSSDK`进行SDK管理
